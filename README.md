# Responsive Video Streaming Homepage (HTML & CSS)

## 📌 Project Overview

This project is a **responsive video streaming homepage** built using **HTML5** and **CSS3**. It recreates the layout and user interface of a modern video streaming platform to practice real-world frontend development concepts.

The project was developed as part of the **SuperSimpleDev HTML & CSS course**, where I learned to build responsive layouts using modern CSS techniques while following industry-standard practices.

---

## ✨ Features

* Responsive page layout
* Navigation header
* Sidebar navigation
* Video grid layout
* Video cards with thumbnails
* Channel profile images
* Video metadata (title, creator, views, upload time)
* Hover effects
* Clean and organized CSS structure

---

## 🛠️ Built With

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid

---

## 📚 Concepts Practiced

This project helped strengthen my understanding of:

* Semantic HTML
* CSS Selectors
* The CSS Box Model
* Flexbox
* CSS Grid
* Positioning (Relative, Absolute, Fixed)
* Responsive Web Design
* Media Queries
* Organizing CSS into multiple stylesheets
* Building pixel-accurate user interfaces
